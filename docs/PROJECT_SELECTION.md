# Pourquoi ces dix sujets ?

Cette sélection privilégie des compétences démontrables par un étudiant : modéliser un problème, écrire du code compréhensible, manipuler des entrées réelles, traiter les erreurs et expliquer les compromis. Elle ne constitue pas un classement statistique des attentes des recruteurs ; aucune enquête auprès de recruteurs n’a été effectuée.

## Références consultées le 30 octobre 2026

- [OWASP Top 10, dépôt officiel](https://github.com/OWASP/Top10) : sensibilisation aux risques applicatifs. Le README consulté annonce la publication du Top 10:2025. Sentinel Log et VaultCheck explorent des notions de journalisation et d’intégrité ; ils ne couvrent ni ne certifient le Top 10.
- [GitHub public roadmap](https://github.com/github/roadmap) : source officielle pour découvrir les directions de la plateforme et les fonctionnalités autour du développement logiciel. Ce document ne classe pas les projets étudiants par employabilité.

La consultation automatisée du dépôt Developer Roadmaps a renvoyé une erreur 404 sur les chemins essayés ; elle n’est donc pas utilisée comme preuve.

## Compétences illustrées

| Compétence | Projets | Preuve dans le code |
| --- | --- | --- |
| Sécurité défensive | Sentinel Log, VaultCheck | Fenêtre temporelle, empreintes, traitement de fichiers |
| Gestion et persistance | StockPilot, BudgetLens | Transactions, audit, SQL paramétré, décimaux |
| Données et recherche | CleanData, DocuIndex | Validation, quarantaine, classement lexical |
| Exploitation | PulseWatch | Délais, erreurs réseau, codes HTTP |
| Algorithmique | FlowDAG, RouteCraft | Tri topologique, cycle, chemin minimal |
| Statistiques appliquées | SensorScope | Médiane, MAD, limites des heuristiques |

Pour une candidature, deux ou trois projets approfondis avec une utilisation concrète apporteront davantage d’éléments à discuter que dix exemples conservés sans personnalisation. Les dix bases permettent de choisir ces spécialités.
